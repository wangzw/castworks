# LLM 流量经沙箱内本地代理与 LLM 网关两级

## 背景

Agent 的 LLM 请求可能持续数分钟，沙箱可能在请求进行中被冻结、快照或销毁。沙箱到 LLM 网关的上游连接在快照与销毁时必然断开；冻结时客户端连接停滞，但 TCP 连接本身不保证维持。HTTP/2 流控与中间层的写超时决定了停滞客户端只能由沙箱内的代理吸收，而不是跨越网络中间层。

Claude Code 的流式看门狗在未收到任何内容时会中止并重发一次；已经收到部分内容时保留截断结果，不重发（[REF-claude-code-network-config](../references.md)）。因此，已向 Agent 转发内容后不得长冻结；重发还需要单次回放缓存，避免重复的上游请求。Anthropic Messages API 的服务器发送事件流包含内容事件与保活事件（[REF-anthropic-streaming](../references.md)），保活事件是冻结期间维持客户端连接的唯一手段。

LLM 网关必须持有真实凭据、校验代、限流、计费、审计，并持久化在途请求与回放存储；本地代理必须保持不被冻结，才能在上游连接断开后重连并按 `request_id` 取回已完成响应。

## 考虑过的选项

### 网关直接容忍停滞客户端

采用它意味着 Agent 直连 LLM 网关，网关在冻结期间保持请求与连接，解冻后继续转发。**被拒**：HTTP/2 流控与中间层写超时会使停滞连接断开；网关要为每个冻结请求保持连接与上游状态；快照与销毁后沙箱内本地连接不存在，无法恢复；客户端看门狗仍会中止。

### 限制冻结时长在客户端超时内

采用它意味着冻结不超过客户端流式看门狗的时限，避免客户端中止。**被拒**：冻结时长由客户端超时决定，而不是由预测等待决定；长等待无法冻结；快照与销毁仍会断开上游连接，且没有回放机制；不同 Agent 的看门狗不同，无法统一。

### 沙箱内本地代理加 LLM 网关两级，按请求选择直通或缓存

采用它意味着本地代理终止 Agent 的连接、附加运行实例令牌并转发到 LLM 网关，并按请求在开始时一次性选择直通或缓存模式。LLM 网关换取真实凭据、校验代、跟踪在途请求并保存回放；冻结时本地代理持有上游连接并缓冲或直通，快照与销毁后按 `request_id` 取回已完成响应。**采用**，见决策。

## 决策

采用两级 LLM 代理：沙箱内的本地代理不被冻结，终止 Agent 的 LLM 连接、附加运行实例令牌并转发到 LLM 网关，并按请求在开始时一次性选择直通或缓存模式。LLM 网关以令牌换取真实凭据、校验代、跟踪在途请求并持久化回放存储；冻结期间本地代理持有上游连接，快照或销毁后按 `request_id` 取回已完成响应。

## 后果

本决策使项目承担以下义务，穷举如下：

- 本地代理必须保持不被冻结，并在 Agent 进程树冻结期间继续运行；它必须支持流式响应、HTTP 与 CONNECT 转发、按请求选择模式，并附加运行实例令牌。
- 直通模式下该请求期间的冻结不超过 `F_stream`；一旦已向 Agent 转发响应内容，不得延长冻结；缓存模式必须缓冲全部内容事件、只转发保活事件，解冻后一次性交付。
- 客户端中止并重发时必须按 `(run_id, generation, request_hash)` 命中单次回放缓存，不得向上游发起第二次请求。
- LLM 网关必须持久化在途请求与已完成响应，按 `request_id` 提供取回；网关实例失联时，控制面必须为其在途请求合成失败唤醒信号。
- 本地代理必须处理令牌轮换；令牌过期或临近到期时，收到 `TokenRotate` 之前不得向网关转发请求。
- 必须把 Agent 的 LLM 基地址配置为指向本地代理；运行实例令牌的持有与沙箱出口约束见 [ADR-host-owns-external-wake-sources](adr-host-owns-external-wake-sources.md)。

承担的代价穷举如下：

- 每个 LLM 请求多一跳；本地代理要处理高并发流式连接，并在冻结期间持有上游连接。
- 缓存模式缓冲完整响应，占用本地代理内存并延迟首次内容交付；直通模式在已转发响应内容后不能长冻结。
- 网关需要保存在途请求与回放数据，带来存储、保留期与清理成本。
- 快照或销毁后上游连接必然断开，恢复依赖网关的回放存储；回放不可用时该请求只能失败。
- 两种模式增加策略复杂度；模式预测错误会导致客户端看门狗中止或冻结时长受限。
- 其他 Agent 的流式重试语义可能与 Claude Code 不同，单次回放缓存的收益随 Agent 而异。

## 失效条件

- Agent 平台支持跨进程冻结的可恢复流，且客户端不会因停滞中止时，本地代理的缓冲与回放不再必要。
- LLM 网关能直接吸收停滞客户端并在沙箱销毁后恢复流，且不依赖沙箱内代理时，两级结构可以合并。
