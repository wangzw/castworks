# 以代围栏沙箱消息与副作用

## 背景

运行实例的生命周期跨越沙箱的创建与销毁，冻结与解冻、快照恢复与销毁重建使同一运行实例在不同时刻由不同沙箱承载。旧沙箱在代递增之后可能仍然存活，并继续发送协议消息、持有运行实例令牌、写入工作区或推进投递游标。

控制面数据库是运行实例状态的唯一事实源，消息、令牌、工作区写入与游标推进是否被接受，必须能由控制面在本地事务内判定，不能等待沙箱提供者的外部确认。出站流在重连后重放未确认消息，投递语义为至少一次，跨代幂等要求接收方能判别一份消息属于哪一代沙箱。工作区在沙箱销毁与重建之间保留，共享文件系统下旧沙箱的写入对新沙箱可见，工作区的写者必须唯一。

以上事实要求存在一个控制面可核验、单调递增、在预配新沙箱之前即可确定的值，用于拒绝过期沙箱的动作。

## 考虑过的选项

### 仅以 sandbox_id 区分新旧沙箱

采用该选项意味着：消息信封、令牌、工作区租约与游标推进携带 sandbox_id，控制面只接受 sandbox_id 等于当前沙箱的动作。

**被拒**：sandbox_id 由沙箱提供者在预配之后分配。销毁重建的窗口中，控制面已经递增代、新沙箱尚未预配，运行实例没有可比较的当前 sandbox_id，围栏判断在该窗口内不可用。sandbox_id 不单调，等值比较只能区分相同与不同，不能判断哪一方更旧，切换前发出、切换后到达的消息与标识被复用的消息因此不可区分。预热池认领与快照恢复改变 sandbox_id 的产生方式，不同提供者的形式与生命周期不同，无法形成跨提供者的统一围栏。工作区租约与令牌需要在预配之前携带围栏依据，而 sandbox_id 在预配之后才存在。

### 依赖沙箱提供者的删除确认作为唯一围栏依据

采用该选项意味着：控制面只在沙箱提供者确认旧沙箱已删除或已停止之后放行新代动作，消息、令牌、工作区写入与游标推进的接受都以该确认为准。k8s 提供者的确认是 Sandbox CR 完成 Pod 删除（[REF-agent-sandbox](../references.md)），Substrate 提供者的确认是 actor 停止（[REF-substrate](../references.md)）。

**被拒**：删除确认是沙箱提供者的异步事实，时延由提供者与集群状态决定，控制面在确认到达前不能放行新代，恢复时延不再由控制面控制。冻结与快照恢复不删除沙箱，删除确认不覆盖冻结与快照恢复，而冻结与快照恢复路径上的旧沙箱动作仍需要判别。旧沙箱在删除确认之前发出的消息确实来自尚未被删除的沙箱，删除确认不能把这类消息判为过期，围栏必须在旧沙箱仍然存活时生效。控制面与沙箱提供者之间的网络分区使确认不可得，围栏随之失效。

### 以运行实例的 generation 围栏全部沙箱侧动作

采用该选项意味着：运行实例的 generation 单调递增，每次预配沙箱之前递增；消息信封、令牌、工作区租约与游标推进都携带 generation，控制面拒绝与当前代不一致的动作。

**采用** — 见决策。

## 决策

采用运行实例的 generation 作为统一围栏依据：generation 单调递增，消息信封、令牌、工作区租约与游标推进都按代围栏。

## 后果

本决策使项目承担以下义务（穷举）：

- 消息信封、令牌、工作区租约与游标推进必须携带并校验 generation；任一载体遗漏代比较即构成围栏缺口。
- 销毁重建时，generation 递增与旧令牌吊销必须在同一事务内完成，之后才允许预配新沙箱。
- 旧代沙箱重连时必须收到围栏拒绝，其看守进程停止投递与副作用并终止 Agent 进程树。
- 新代接管工作区仍以旧租约到期或沙箱提供者确认旧沙箱删除为前提，代围栏不替代该前提。
- 围栏拒绝必须与消息丢失可区分，否则过期动作被拒会表现为静默丢弃。

承担的代价穷举如下：

- 同一代内的多个沙箱实例携带相同的 generation，代围栏不能区分它们；快照恢复与预热池认领路径上的单写者仍由工作区租约与运行实例所有者租约保证。
- generation 递增前发出、递增后到达的消息一律被拒绝，只能依靠至少一次投递的重放与投递意图日志重新达成，产生重复投递与状态对账。
- 消息接收、令牌换取、租约续约与游标推进各自增加一次代比较与拒绝路径。
- generation 在旧沙箱仍需继续服务的场景下被递增时，该代沙箱的动作一并被围栏，只能通过重建路径恢复，代价是一次完整的沙箱恢复。
- 沙箱提供者的删除确认仍在新代接管工作区时被需要，围栏没有消除对提供者确认的依赖。

## 失效条件

- 同一运行实例在一个代内出现多个可写沙箱实例，且工作区租约与运行实例所有者租约无法把它们串行化时，generation 不能区分这些实例，围栏依据需替换为每沙箱实例单调且控制面可核验的标识。
- 沙箱提供者提供控制面可核验的全局单调实例序号，覆盖预热池认领、快照恢复与跨提供者路径，并在预配之前确定时，generation 的跨机制统一作用被该序号取代。
- 围栏拒绝计数中同一代的拒绝比例持续非零，表明代比较的输入并非只来自当前沙箱实例，代围栏的判定前提不再成立。
