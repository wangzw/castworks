# connectorhub

`connectorhub` 把外部系统的 webhook、状态式轮询与订阅接入控制面，以连接器事件日志和订阅完成事件向运行实例交付外部事件，并为每个运行实例生成出口策略。连接器负责外部系统定义、事件接入、订阅与完成条件，不执行第三方操作；出口策略描述该运行实例可用的外部系统、允许主机与凭据占位符替换规则；平台出口代理是 k8s 路径上落地这些规则的网关，终止本地代理的 CONNECT 或 HTTP 前置请求与透明拦截器的 CONNECT 隧道，按运行实例白名单鉴权并替换凭据占位符后转发到允许主机。Substrate 路径的出口由 Substrate 出口网关承担。
